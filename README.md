📚 FlashCards – Study & Quiz App

FlashCards is a simple educational Android application designed to help students learn, revise, and test their knowledge using digital flashcards.

The app organizes flashcards into different subjects or categories such as Computer Science, Math, and General Knowledge. Users can select a category, view questions one by one, reveal the answers, and move between flashcards while practicing.

The application also allows users to add new flashcards, edit existing flashcards, and delete unwanted flashcards.

Main Features
📖 Category-based flashcards
❓ Question and answer system
▶️ Practice/Quiz mode
➕ Add new flashcards
✏️ Edit flashcards
🗑️ Delete flashcards
🔄 Move between previous and next cards
🎉 Quiz completion screen
🎨 Clean and minimal user interface

In simple words:

This project is an educational flashcard application that helps students study and revise different subjects by answering questions and reviewing their answers.
