## ✨ Key Features

- **🎨 Modern Glassmorphism UI:** Features a custom background gradient paired with translucent, frosted-glass card containers and subtle borders.
- **✍️ Typewriter Animation:** Engaging character-by-character typing animation applied dynamically whenever a new quote is loaded.
- **🔄 3D Snap Carousel:** An interactive horizontal carousel equipped with snapping behavior, dynamic scaling, fading, and 3D cylindrical rotation for browsing collections seamlessly.
- **💖 Favorites & Interactions:** Easily favorite quotes, copy them directly to your system clipboard with a toast notification, or share them via external apps using native Share Intents.
- **🎲 "Surprise Me" Mode:** Instantly shuffles to a random quote with smooth animated content transitions.

---

## 🛠️ Tech Stack & Architecture

- **Language:** [Kotlin](https://kotlinlang.org/)
- **UI Toolkit:** [Jetpack Compose](https://developer.android.com/jetpack/compose) (100% Declarative UI)
- **Design System:** Material Design 3
- **Animations & Graphics:** Compose Animation API (`AnimatedContent`, `animateFloatAsState`), `graphicsLayer` for 3D perspective transforms.
- **State Management:** Compose State (`mutableStateOf`, `remember`, `LaunchedEffect`)
